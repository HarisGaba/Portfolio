# Haris Gaba Portfolio — Static Package

This package is a standalone portfolio website built with plain **HTML, CSS, and JavaScript**. Open `index.html` in a browser to view it; no Node.js installation or build process is required.

The included contact form opens the visitor’s default email client with a message addressed to `fahimgaba9@gmail.com`. The LinkedIn and GitHub links are already connected to the supplied public profiles.

## Resume download

To enable the resume download button, copy the final PDF into the `assets` folder and name it exactly:

```text
Haris-Fahim-Gaba-Resume.pdf
```

The button checks for this file and displays a clear message if the PDF has not yet been added.

## Package structure

| Item | Purpose |
|---|---|
| `index.html` | Page structure and portfolio content |
| `styles.css` | Responsive styling and visual design system |
| `script.js` | Navigation, animations, skills tabs, contact form, and resume handling |
| `assets/` | Included custom visual assets and the location for the resume PDF |
