# UI Redesign Direction — Studio Ledger

The revised portfolio will move away from the prior dark editorial atlas treatment and toward a **professional studio ledger**: a confident, high-contrast interface that feels designed by a thoughtful product-minded developer rather than assembled from decorative portfolio patterns.

The page will use an **ivory workspace, charcoal typography, and a restrained cobalt signal color**. The navigation will remain consistently readable in an opaque top bar, without any image logo. The hero will be restructured as a crisp two-column introduction with a compact visual field, high-information metadata, and clear calls to action. Each following section will alternate between structured whitespace, ruled lines, and practical information modules rather than repeating card grids.

Motion will have a specific purpose. The page will use a short entry preloader, line-draw effects, staggered text reveals, selected-state transitions, gentle project-image movement, and button press feedback. Motion will use transform and opacity, stay under half a second for routine interactions, and respect reduced-motion preferences.

The content, profile links, contact behavior, and resume setup will remain unchanged. Only the visual system, layout composition, and animation language will be replaced.
